
# SQL & Math Practice

A personal learning project containing SQL exercises using MySQL and fundamental calculus problems.

## Topics Covered

### SQL
- Aggregate functions: `AVG()`, `MAX()`, `COUNT()`
- Date and time calculations
- Filtering with `WHERE` and `LIKE`
- Joining multiple tables
- Grouping and sorting results
- Updating and deleting records
- Subqueries and finding the latest record per group

### Mathematics
- Implicit differentiation
- Chain rule
- Derivatives of polynomial functions
- Geometric interpretation of derivatives

## Technologies
- MySQL
- SQL
- Mathematics and calculus

## Purpose

The goal of this project is to strengthen my problem-solving skills,
understand relational databases, and practise mathematical concepts.
