
# Implicit Differentiation

## Problem

Find dy/dx if:

x² + y² = 25

## Step 1: Differentiate both sides

Differentiate with respect to x:

d/dx(x² + y²) = d/dx(25)

Using the power rule and chain rule:

2x + 2y(dy/dx) = 0

## Step 2: Isolate dy/dx

Move 2x to the right:

2y(dy/dx) = -2x

Divide both sides by 2y:

dy/dx = -2x / 2y

## Final Answer

dy/dx = -x/y

## Explanation

Implicit differentiation is useful when y is not explicitly
expressed as a function of x.

The chain rule is necessary because y depends on x:

d/dx(y²) = 2y(dy/dx)

The equation x² + y² = 25 describes a circle with radius 5.
The derivative -x/y gives the slope of its tangent line,
where y is not zero.

## Key Concepts

- Power rule
- Chain rule
- Implicit differentiation
- Derivatives and tangent lines
